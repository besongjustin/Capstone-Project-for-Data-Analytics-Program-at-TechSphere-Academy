Logistics Operation Analysis Dashboard
Capstone Project — Data Analytics Program at TechSphere Academy
By Justin Besong

Project Overview
This project is the Capstone submission for the Data Analytics Program at TechSphere Academy. It presents a fully interactive Power BI dashboard analyzing the logistics operations of a fictional company across revenue performance, delivery efficiency, fleet costs, and driver safety.
The dashboard was built from a relational dataset of 14 tables and delivers actionable insights across 4 report pages.

Tools Used

Power BI Desktop — Dashboard design and visualization
DAX — Calculated measures and KPIs
Power Query — Data cleaning and transformation

Key Insights

The operation generated $262.5M in revenue with a profit of $161.2M — a 61% profit margin
On-time delivery rate stands at 55.67%, meaning nearly 1 in 2 deliveries is late
First Group is the highest-value customer at $9.1M in revenue
Automotive leads all product types in profitability at $29.3M
Fleet fuel costs totaled $95.59M against $5.73M in maintenance costs
TRK00003 recorded the highest maintenance cost at $90K
170 safety incidents resulted in $1.60M in vehicle damage and 33 injuries
DOT Violations are the most common incident type at 22.94%
Top driver William Wilson completed 1,429 trips — more than double the bottom driver
